# Customer Sales Analysis Dashboard – Power BI

## Project Overview

An interactive Power BI dashboard developed to analyze customer sales,
revenue, profit, product performance, and regional trends.

## Business Problem

The objective of this project is to help business stakeholders understand:

- Total sales and profit performance
- Top-performing products
- Customer purchasing behavior
- Regional sales trends
- Monthly revenue trends
- Profitability by category

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel
- Data Modeling
- Data Visualization

## Key Features

- Interactive KPI dashboard
- Sales and profit analysis
- Customer segmentation
- Product performance analysis
- Regional analysis
- Monthly/Yearly trend analysis
- Interactive filters and slicers

## Key KPIs

- Total Revenue
- Total Profit
- Total Customers
- Total Orders
- Average Order Value
- Profit Margin

## Data Preparation

Data was cleaned and transformed using Power Query.

Major transformations included:

- Removing duplicates
- Handling missing values
- Changing data types
- Creating calculated columns
- Data validation
- Creating relationships between tables

## DAX Measures

Examples:

- Total Sales
- Total Profit
- Profit Margin %
- Average Order Value
- Customer Count
- Year-over-Year Growth
